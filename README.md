Entry for the make.fun competition "The poem about two agents agreeing"
($35 shared by the top 20). `main.py` (Python 3.13, stdlib only, no network)
writes one short original poem to `/output/entry.txt` — two agents, each
holding a key cut for a different lock, who agree not by arguing over whose
key is true but by making a third key together.

Run it with:

```sh
python3 main.py
```

The output is deterministic: the same poem, byte for byte, on every run.
